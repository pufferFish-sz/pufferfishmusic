CMU

15-666 Computer Game Programming

  • C++
  • Custom Engines
  • OpenGL

In this course we programmed a new game nearly every week, almost from scratch, in C++ — covering the art pipeline, 3D engines, sound, and multiplayer. Systems like a PNG → PPU466 import pipeline, physics collision, animation, gameplay, lighting improvements, and camera movement all had to be user-defined.

Among the games: a 2D game about a frog that eats bugs, a 3D batting game against flying bugs, and a duck-stepping rhythm game. All the work and code is on GitHub: base1 · base3

VR

VR Interactive Music & Mech Fighting

  • Technical Sound Design
  • Wwise
  • Interactive Music
  • VR

A VR fighting game against a crab from the Classic of Mountains and Seas, developed by a team of five — I was the technical sound designer.

After composing the music with Kontakt and BBC Symphony Orchestra libraries, each stem was arranged in Wwise. The soundtrack changes with the game state, transitioning smoothly from intro exploration into battle, and an outro section plays the victory/defeat phrase immediately after the fight — achieved by jumping straight to the last measure on a game-state switch. The project is on GitHub.

Waves — 3D Battleship Simulator

Waves is a battleship simulator developed with college friends, starting from the Level Upstate game program. I made all of the audio assets in the game — UI, in-battle, environmental ambience, and music. The build is on itch.io.
