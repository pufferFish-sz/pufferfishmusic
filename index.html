Tencent Games — Internship

The Hidden Ones — Character SFX Redesign

Programs: Wwise, REAPER, Python + WAAPI

Role: Sound Design / Implementation, Tools

The Hidden Ones is a 3D combat action game built around Chinese martial arts. Since PVP combat is a major feature, I emphasized defining each character’s personality through their distinct ability sounds and spatially dynamic effects. The redesign shown here is for Ruhua, a mechanical puppet — no emotions, powerful, elegant, with a sense of eeriness that often surrounds her.

Audio tools — batch VO import over WAAPI

Besides implementing in-battle character SFX through the engine’s animation and scene editors, I extended the audio team’s tooling with Python and WAAPI: batch-importing VO lines into switch or random containers in Wwise and auto-populating the corresponding events and soundbanks — handy when dealing with hundreds of VO lines at a time.

Disclaimer: all redesign materials shown have already been released on the market or through alpha testing. No copyright infringement intended.

AFK Arena / AFK Journey — UI SFX & VO Pipeline

Programs: REAPER, Lua ReaScript

Role: Sound Design, Pipeline Tools

AFK Arena and AFK Journey are SLG-mechanic-heavy RPG mobile games that lean into magical, whimsical, fantasy-flavored aesthetics. Here is an example of the UI SFX I made during the internship.

Audio tools — ReaScript batch VO processing

The team’s pain point was the massive amount of narrative VO to process. I wrote ReaScripts in Lua that manipulate samples directly on each track: automatically splitting long WAV files into separate vocal lines, moving each into its own track, and gluing media items per track — so processed files batch-export with the correct naming conventions.

Team Project

VR Interactive Music & Mech Fighting

Programs: Wwise, Kontakt, BBC Symphony Orchestra

Role: Technical Sound Designer, Composer (team of 5)

A VR fighting game against a crab from the Classic of Mountains and Seas. After composing the music, each stem was arranged in Wwise: the soundtrack transitions smoothly from intro exploration into battle with the game state, and an outro plays the victory/defeat phrase immediately after the fight — by jumping straight to the last measure on a game-state switch. Code on GitHub.
