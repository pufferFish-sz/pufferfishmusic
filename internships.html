Tencent Games

The Hidden Ones

  • Character SFX
  • PVP Combat
  • Wwise
  • Python + WAAPI

The Hidden Ones is a 3D combat action game built around Chinese martial arts. Since PVP combat is a major feature, I emphasized defining each character’s personality through their distinct ability sounds and spatially dynamic effects.

The redesign shown here is for Ruhua, a mechanical puppet. She has no emotions — powerful, elegant, yet with a sense of eeriness that often surrounds her.

Tools development — WAAPI

Besides implementing in-battle character SFX through the game engine’s animation and scene editors, I added new features to the audio team’s tooling. Using Python and WAAPI, I built an option to batch-import VO lines into switch or random containers in Wwise, automatically populating the corresponding events and soundbanks — handy when dealing with hundreds of VO lines at a time, with categorization customizations for different name types and usages.

Lilith Games

AFK Arena / AFK Journey

  • UI SFX
  • VO Pipeline
  • REAPER
  • Lua ReaScript

AFK Arena and AFK Journey are SLG-mechanic-heavy RPG mobile games that lean into magical, whimsical, fantasy-flavored aesthetics. Here is an example of the UI SFX I made during the internship.

Tools development — ReaScript

The audio team’s pain point on these projects was the massive amount of narrative VO to process. I wrote ReaScripts in Lua that manipulate samples directly on each track: automatically splitting long WAV files into separate vocal lines, moving each into its own track, gluing media items per track, and more — all so processed files could be batch-exported with the correct naming conventions.
